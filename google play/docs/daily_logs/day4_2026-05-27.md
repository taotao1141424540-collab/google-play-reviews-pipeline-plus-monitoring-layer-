# Day 4 Log - 2026-05-27

## Goal
Stand up **theme tagging pipeline** (BQ3/BQ4): rule-based multi-label themes on
`clean_en_only`, generate theme summary tables for dashboard Page 3, and run a
first validation pass to tighten obvious false positives.

## Prerequisites
- `data/processed/clean_en_only.csv` (Day 1–2 cleansed English subset, 10940 rows)
- `docs/business_design/business_scope_three_layer_design.md` §11 (theme taxonomy)

## Work Completed

### 1) Theme dictionary v2 — `config/themes.yml`
- 18 themes (13 negative + 5 positive) per design doc §11.
- **v2 changes (Day 4 validation pass):**
  - `fun_addictive`: added exclude rules for negation phrases
    (`not fun`, `used to be fun`, `wasn't fun`, `takes the fun out`,
    `no longer fun`, etc.) — biggest source of false positives in low-star reviews.
  - `account_login`: removed bare `login` / `account` tokens; require phrase form
    (`login problem`, `cannot log`, `lost progress`, …) — was massively
    overmatching neutral references.
  - `visual_graphics`: require qualifier (`great graphics`, `visually stunning`),
    not bare `graphics` token; added exclude (`bad graphics`, `graphics suck`).
  - `updates_new_content`: added exclude for negative update phrases.
  - `difficulty_progression`: expanded keywords (`too difficult`, `super hard`,
    `can't pass`, `can't get past`, `stuck on the same level`, …).

### 2) Review-level tagging — `scripts/06_insights/build_review_themes.py`
- Input: `clean_en_only.csv` + `themes.yml`
- Output: **`data/processed/reviews_with_themes.csv`** (10940 rows, multi-label)
- Schema: original review fields + `theme_tags` + `n_themes_hit` + `theme_<id>` flags.

### 3) Theme summary tables — `scripts/06_insights/build_theme_summary_tables.py`
Outputs under `reports/tables/`:

| File | Grain | Purpose |
|------|-------|---------|
| `theme_summary_overall.csv` | theme | pool-level share / mean / rating_gap / share_low_1_2 (BQ3+BQ4) |
| `theme_summary_by_app.csv` | App × theme | per-app theme profile for App×Theme heatmap |
| `low_star_theme_summary.csv` | theme | concentration in 1–2★ reviews (BQ3 pain points) |

### 4) Validation sample — `scripts/06_insights/sample_theme_validation.py`
- Stratified across low (≤2★) / mid (3★) / high (≥4★) bands per theme +
  zero-tag rows for recall check.
- Output: `reports/tables/theme_validation_sample.csv` (190 rows; blank
  `precision_correct` / `missed_theme` / `notes` for manual review).
